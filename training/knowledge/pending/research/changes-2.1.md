# 2.1 相对 2.0 的变化 (只列影响玩法和设计的)

> 整理于 2026-10-31。本机游戏 2.1.24 + 太空时代。
> 依据: 本机游戏目录 `data/changelog.txt` 的 2.1.7 ~ 2.1.24 各节 (可信度 1), 本机原型 (`data/space-age/prototypes/…`、`doc-html/prototype-api.json`, 可信度 1), 官方开发周报 FFF #440 ~ #449 (可信度 2)。

> 版本时间线: FFF #440 公布计划 (2026-05-29) → 2.1.7 第一个公开实验版 (2026-06-23) → 2.1.13 (08-05, 敌人扩张回调) → 2.1.21 (10-06, 平台阻力和星岩伤害定稿) → FFF #449 宣布 2.1 稳定 (10-23) → 2.1.24 (10-27, 本机)。

可信度: 1 = 本机游戏自带 (更新日志/原型/API 文件); 2 = 官方网站和论坛。和第一版的关系: 印证 / 冲突 / 新知, 编号对应 `docs/lessons-v1.md`。

# 蓝图库

`./bp list` 用的蓝图, 本机没有积累时用这里的。由 `tools/export-public.ts` 导出, 不要手改。

- `generated/`: 自己的生成器 (`tools/generators/`) 产的积木和喂料实测。
- `community/`: [Brian's Blueprints](https://github.com/bcwhite-code/brians-blueprints) by bcwhite-code, CC0 1.0 (见 `community/LICENSE`), 迁移到 Factorio 2.1 的版本。
- `index.jsonl`: 每张的出处、许可、大小、建筑数和沙盘实测。

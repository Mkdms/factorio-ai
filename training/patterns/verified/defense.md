### P-def-01 【分歧】什么时候布防: 新地星是"污染云碰到虫巢之前", 句芒是"农场建好之前", 不是开局先修墙
- 情况: 新地星开局; 句芒落地
- 做法: 新地星: 打开地图污染图层, 污染云碰到虫巢之前备好机枪炮塔和弹药; 按虫子的实际行为再建防御是合理做法 (N23); 产量上去以后进攻才会来 (N20); 2.1 下灰/蓝瓶阶段就可能有扩张巢落进污染云, 军事投入要提前 (N24, D4, 可能过时: 2.1.13 回调); 紫瓶前后大型虫出现, 先升级前哨防御再上核电 (N25)。句芒: 防线建好前别加工果子 (G25), 因为孢子只来自农业 (G3)
- 为什么: 进攻只来自吸到污染/孢子的虫巢 (D1); 新地星开局没污染就没进攻, 墙是浪费; 句芒一开农业就有孢子
- 代价 / 不适用: 先防线后工厂的原则只对句芒农场成立, 不推广到新地星开局 (research README 第二轮冲突表); 死亡世界另算

### P-def-02 围什么: 新地星围污染云 (防线推到云外只面对扩张队)、句芒围农场、祝融避让领地、雷神防雷、玄冥防冻
- 情况: 每颗星定防线范围
- 做法: 新地星: 防线推到污染云外, 只面对扩张队; 墙做成凸形不留凹口, 借湖和河缩短墙 (D5, D6); 句芒: 围农场 (孢子源), 防线放在孢子云外, 特斯拉炮塔覆盖略重叠 (G25, D21); 没农场的区域不会被主动攻击 (2.0.27 起蠕动不再主动攻击孢子源, 但会回应重炮); 祝融: 不围, 避让撼地虫领地, 建筑离边界留余量 (V27); 雷神: 没有敌人, 建筑中心落在避雷针蓝圈内 (D30); 玄冥: 没有敌人, 威胁监控改盯温度和电 (A29, D34)
- 为什么: 太空时代每颗星单独算进化和污染 (D1); 2.1 扩张安全距离 64 → 96 格 (D3); 五足虫只在浅水筑巢 (G5)
- 代价 / 不适用: "只防收获区的孢子云范围会很快被新巢盯上" (EL20, 2.0 时代, 可能过时) → 句芒围农场还要加重炮控地盘 (P-def-10)
- 关联: 污染/孢子范围由产量和插件决定 (P-def-19); 威胁图按污染云 + 扩张候选区算 (research README)

### P-def-03 【分歧】清巢还是围巢: 清掉推进化且清过的地方是 2.1 扩张首选; 围巢不推进化但巢照样吸污染出兵
- 情况: 污染云边缘有虫巢
- 做法: 清巢派: 重炮稳定供弹最终把射程内的巢清光, 把虫巢挡在污染云外 (D18); 但 2.1 起候选区偏向已清理的空地, 清完巢后反而更危险 → 重炮覆盖要一直维持, 清巢后立刻布防 (EL11, D18); 围巢派: 用防御围住虫巢而不是清掉, 清掉的地方会被更大的巢重新占 (D5); 云团外的巢清不清有争议: 延缓扩张 vs 拆巢推高进化 (N23)
- 为什么: 进化三因子: 时间 0.000004/秒、污染 0.0000009/单位、每拆一巢 0.002, 总值按 e = x ÷ (1 + x) 压缩且增量乘 (1 − e)² → 进化 0 时拆巢 +0.002, 0.5 时只 +0.0005 (D1, EL1); 2.1 扩张巢大小向地图自带的巢看齐, 建巢冷却 30 秒 (EL11)
- 代价 / 不适用: 2.1.7 起被堵住出不了兵的虫巢会喷伤害性酸云, "用墙围死虫巢"和"堵出兵格"的老套路不能用 (changes-2.1 第 3 节, D35); 2.1.13 之前的"扩张过强"体感已回调 (EL12)
- 关联: P-def-10 (重炮); progression.md P-prog-16; 雷达覆盖区内建巢有告警 (2.1.13) 可触发清巢任务
- 流派: 通用
- 出处: D18 (论坛 2025-03 + FFF #445 2026-08, 3/2); EL11 (FFF #445, 2); D5 (论坛 2026-07, 3, 可能过时); N23 (论坛 2026-02, 3); D1、EL1 (wiki + 本机 map-settings, 2/1); D35 (视频 AVADII 2026-05 vs 本机 2.1.7, 4/1); EL12 (论坛 2026-07, 3)

### P-def-04 零散建筑压扩张 ("胜利电线杆"): 2.1 下是否还有效待核实
- 情况: 想便宜地降低基地附近的扩张概率
- 做法: 扩张候选区按附近建筑打分, 和建筑大小、造价无关 → 零散的管道/墙块就能压低附近扩张概率 (D2); 2.1.7 ~ 2.1.12 有人打开"扩张候选"调试图层, 在基地周围零散放墙块压住候选区, 认为又能用了 (D4); 句芒有人建议每区块放十几块墙 (EL20)

### P-def-05 炮塔按"敌人 × 抗性"选, 不按"最高档": 激光对重踏 80%、对撼地虫 100%、对中型以上星岩 90 ~ 99%; 特斯拉在太空没用
- 情况: 任何星球选炮塔
- 做法: 五足虫: 重踏 物理 2/50%、激光 80%、冲击 80%; 飞弹 物理 2/10%、激光 50%; 蠕动 激光 50%; 三种都没有电、火、爆炸抗性 (G21, EL3) → 特斯拉炮塔打重踏, 火箭炮塔打飞弹, 机枪/激光打蠕动 (G25); 撼地虫: 火/激光/冲击 100% 免疫, 爆炸 60%, 物理 50%, 电 20/20%, 毒 10% (D23, EL4) → 物理 (贫铀弹匣/炮弹)、电 (放电防御模块)、毒 (剧毒胶囊)、核; 星岩: 大型、巨型先减 2000 / 3000 物理, 激光 90 ~ 99%, 电、火 100% 免疫 (SL6) → 机枪炮塔只打小中型, 火箭炮塔打大型, 磁轨炮塔打巨型, 激光只打小型, 特斯拉无用 (S13, SP12, SA9); 新地星虫子: 火焰炮塔伤害最高、激光收尾, 机枪"已经不是最好的"(D7, 有争议)
- 为什么: 抗性表在本机原型里, 第一版"按敌人血量、射程、抗性选武器"是做对的 (lessons 第 3 节)
- 代价 / 不适用: 传说炮塔只加射程 (×1.5) 不加伤害, 射程太长会把弹药浪费在撞不上的星岩上 (QL3, SP14); 火箭炮塔对撼地虫 (爆炸 60%) 也不是最优
- 关联: 补给链随炮塔变 (P-def-08/09); 审查闸门要有"炮塔选型表按敌人 × 抗性查" (research README 第三轮)
- 流派: 通用

### P-def-06 【分歧】新地星墙和炮塔怎么搭: 凸形双层墙 + 串联供弹 + 混用; "机枪已不是最好"vs"火焰 + 墙 + 重炮就够"
- 情况: 新地星中后期防线
- 做法: 墙凸形不留凹口, 双层墙让虫子碰不到炮塔, 墙后炮塔机械臂串着供弹 (一座坏了后面还有料), 新地星上墙基本必须 (D6); 各种炮塔混用: 火焰炮塔伤害最高、激光收尾; 有人只用火焰 + 墙 + 重炮守住; 特斯拉炮塔只放虫卵区附近 (D7); 高进化: 双层墙配激光 + 少量机枪 + 火焰, 100+ 巨兽型撕咬虫能直接撕开第一道墙, 没有漏斗引导时墙阵更安全, 重炮是中后期最终答案 (EL14); 有人故意留缺口让虫子先咬炮塔 (D6, 有争议); 火焰炮塔只打 120° 扇面, 射程 30 最近 6, 2.1.7 起可朝 8 个方向 (D8)
- 为什么: 巨兽型 0.9 起出现, 小/中/大/巨兽血 15 / 75 / 375 / 3000, 物理固定减免 0 / 4 / 8 / 12 + 10% (EL2) → 高进化下标准弹匣基本无效
- 代价 / 不适用: 火焰炮塔和建设机器人冲突 (P-def-07); 2.0.7 起炮塔 (重炮除外) 可设目标优先级 (D8)
- 关联: P-def-07/08/10
- 流派: 通用 (防线生成器按"凸形 + 双层墙 + 串联供弹"出几种方案比)
- 出处: D6、D7 (论坛 p=666045 2025-03-16 ~ 18, 3); EL14 (Steam/论坛摘要 2023 ~ 2026, 3, 可能过时); D8 (wiki 火焰炮塔 2026-09-30, 2); EL2 (本机原型, 1)

### P-def-07 火焰炮塔的火会烧死来修墙的建设机器人: 少放、机器人指令平台离墙远、或改激光/贫铀机枪
- 情况: 有机器人自动修理的防线 (无人值守的前提)
- 做法: 对策四选: 少放火焰炮塔; 机器人指令平台离墙远一点 (机器人来得慢反而安全); 燃料伤害别研究太多 (火焰炮塔吃两次伤害加成, 研究 +160% 实际约 +576%); 或改用激光炮塔/贫铀弹匣机枪 (D9); 有人试过开火时用电路关掉机器人指令平台, 持续进攻下效果不稳 (D9)
- 为什么: 机器人还会互相修理, 结果成片损失 (D9)
- 代价 / 不适用: 火焰炮塔对五足虫有效 (无火抗) 但对撼地虫和星岩 100% 无效 (D8); 不能放太空平台 (D8)
- 关联: P-def-18 (修理自动化); progression.md P-prog-08
- 流派: 通用
- 出处: D9 (论坛 p=643750 2024-11-22 ~ 23, 3); D8 (wiki 2026-09-30, 2)
- 状态: 待核实 (research README 列为直接影响无人值守设计)

### P-def-08 补弹自动化: 炮塔不请求弹药、蓝图弹药只补一次; 白瓶前传送带 + 机械臂, 白瓶后蓝箱 + 机械臂; 热能机械臂断电也有弹

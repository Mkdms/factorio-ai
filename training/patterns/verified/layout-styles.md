# 布局流派 (主线、城市块、火车网、机器人基地、寿司带、直塞、黑盒)

> 2026-11-01 从三轮检索提炼 (`docs/research/players/`), 格式见 [README.md](README.md)。编号后括号 = 来源、日期、可信度 (1 本机 / 2 官方 / 3 社区 / 4 视频)。已核实的引用 `knowledge/facts.md` 编号。

### P-style-01 主线: 红绿瓶到蓝瓶的中期首选, 只放"3 个以上配方要用、且比原料紧凑"的东西
- 情况: 新地星第一版基地, 每分钟 30 ~ 120 瓶
- 做法: 铁板/铜板/钢材/电路板/塑料/齿轮等走平行带组成主线, 产线从主线侧向分出去; 铁板按 4 条一组 (地下带能跨), 每 4 条留 2 格空, 产线间留 3 ~ 10 格 (P28); 主线上只放用得多 (≥ 3 个配方) 且比原料更紧凑的东西 (P29); 新手版用单侧"带肩"的主线, 第一个正式工厂以 30 SPM 为目标 (P30); 有了物流机器人后可逐步用机器人替代, 量很大时改火车 (P28)
- 为什么: 防意大利面、原料集中、以后从主线分出去就能扩 (P28); 新手最容易犯的是"假主线" (带子不满还一直加带)
- 代价 / 不适用: 带子多、占地大、宽了难管 (P28); 煤超过一条带就进入大基地范围, 主线不实用 (P29); Steam 有人干脆建议太空时代直接意大利面 (P29); wiki 主线教程没提太空时代 (P28)
- 关联: progression.md P-prog-02 (先小后大: 主线就是"第一版小基地"的形态); 主线末端要有回收/销毁出口 (logistics-choice.md P-logi-12); 换铸造厂后"板材主线"可能被"熔融金属管线"取代 (P-style-07)
- 流派: 主线 (本条)
- 出处: P28 (wiki 主线教程 https://wiki.factorio.com/Tutorial:Main_bus 2025-03-12, 2); P29 (Steam 讨论 2024-11-13, 3); P30 (视频 Strategic Sage 2024-12-05, 4); Q1 (队友, 老玩家本人, 联机群聊 2026-11-03, 3: "要么用总线架构, 所有原材料和低级材料都平行拉一条长线, 然后用分流器取出来"; 另一条路是封装模块 P-style-08; 他把"铁集中再分配"叫"下一阶段的问题", 和 P-style-12 先能跑再换流派一致)
- 状态: 待核实
- 沙盘怎么比: 45 瓶/分钟 (红绿蓝), A = 4 带主线, B = 意大利面 (各线独立矿→炉→机); 比占地、带子数、到 45 瓶的时间, 以及之后加紫瓶时要动多少

### P-style-02 意大利面 / 有机布局: 开局最快, 代价是扩张时推倒; 留 3 倍空间
- 情况: 开局前 1 ~ 2 小时, 或高虫设置下的速通
- 做法: 不规划主线, 每条产线自己找矿、自己炼、自己组装; 新手贴: 留出比预想多 3 倍的空间, 比例/火车/电路都不是上天的必要条件, 先能跑起来 (N4); 600% 虫巢下 2 小时 6 分离开新地星, 思路是尽快上天不是清虫 (N26)
- 为什么: 开局产量小, 规划的成本比收益高; 2.0 的触发式科技让早期更像"做事解锁"而不是"攒瓶"(N3)
- 代价 / 不适用: 第一版教训 #8 (297 个模块乱堆) 就是意大利面没有阶段闸门的后果; 过了蓝瓶一定要换流派 (P-style-12)
- 关联: progression.md P-prog-01 第 ①② 段; defense.md P-def-01 (开局不修墙)
- 流派: 意大利面
- 出处: N4 (Steam 2024-10-28 ~ 30, 3); N26 (B 站视频 BV1XXHD6sErk 2026-10-08, 4); N3 (论坛 2025-06, 3); lessons-v1 #8

### P-style-03 城市块: 128 格适合中期紧凑基地, 256 格适合 1000+ SPM; 块尺寸由最长列车、机器人指令平台覆盖、路口后区段一起定
- 情况: 紫瓶以后、准备上火车网
- 做法: 用网格对齐, 每块一种产品或一组产品, 块间铁路、块内机器人或传送带; 128×128 造价低、机器人覆盖好, 适合中期; 256×256 能放多个车站, 适合 1000+ SPM; 块大小决定等候区和路口容量 (P31, ML13); 100×100 的块放不下 4 列 1-4 车时, 有人改 1-2 / 1-1, 或改 250 米块让一半数量的 1-4 列车跑一半频率 (ML14); 教程顺序: 开网格 → 32×32 → 64×64 → "推荐 128×128" → 铁路网和圆形路口 → 模块化车站 (ML13); Nilaus 的"城市块 2.0"按太空时代改了前中后期例子 (P31)
- 为什么: 块是"可复制单元", 换铸造厂/电磁工厂时只换块里的机器不动骨架 (progression.md P-prog-12); 机器人指令平台物流半径 25 (50 格宽) 和 128 格块对得上 (ML13)
- 代价 / 不适用: 块越大等候区越长、机器人越容易跨块; 2.0 新轨道的 4 格间距模块蓝图是 32×32 (T6), 块尺寸要是 32 的倍数; 高架有自己的 2×2 网格 (ML12)
- 关联: 块内机器人网必须不重叠 (logistics-choice.md P-logi-03); 块间车站的箱子规则 (P-logi-02); 路口出口后第一区段 ≥ 最长列车 (ML11)
- 流派: 城市块 (本条)
- 出处: P31 (视频 Nilaus 2025-03-06、Slash Blueprint 2026-10-10, 4); ML13 (视频 Slash Blueprint 2026-09-06, 4); ML14 (论坛/Reddit 摘要 2020 ~ 2024, 3, 可能过时); T6 (FFF #377 2023-09 + wiki 铁路 2026-10-22, 2); ML12 (论坛官方 2025-01, 2/3)
- 状态: 待核实 (research README 第三轮建议: 块尺寸参数化 128/256)
- 沙盘怎么比: 同一套 1-4 列车 + 4 种产品, A = 128 格块, B = 256 格块; 比铁路长度、等候区溢出、机器人跨块次数、每块能放的机器数

### P-style-04 火车网: 原料车和成品车分开走, 不用环岛, 等候区并联
- 情况: 城市块或多矿区基地的铁路骨架
- 做法: 9450 SPM 老基地的"环形路": 中心区被 10 线铁路环围住, 外圈再围其他工厂, 原料列车和成品列车分开 (ER22); 环形路线能容纳的车少于要绕它走的车就必然死锁, 小圈两列车就能互锁, 布局生成器直接不用环岛 (T4); 等车停支线等候区不停主线, 进等候区用常规铁路信号、出用联锁铁路信号, 每个站台各成一个区段; 并联式等候区可扩展、省地、可多站共用 (T5); 路口前和路口内用联锁铁路信号, 出口用常规铁路信号, 出口后那段必须放得下最长列车 (T1, T2, ML11); 两个挨得很近的路口当一个路口 (T2)
- 为什么: 死锁 = 一圈车互相等; 路口是唯一会互相等的地方
- 代价 / 不适用: wiki 信号教程是 1.1 时代 (2023-02), 没写 2.0 的新轨道 (弯道半径 11 → 13, 平行间距 2/4/6, 32×32 模块) (T6); 规则仍通用但模板要按 2.0 几何重做。沙盘已核实: 90° 弯 = 曲轨 A B B A、占 13 × 13 格; S 弯 = 半段曲轨 + n 段半斜轨 + 反向半段, 横移 2 + 2n 格; 高架同形, 弯道支架跟着轨斜放 (facts rails.turn-90-radius-13 / rails.s-bend-any-length / rails.elevated-curves-same-shapes ✅); 拼轨用 src/blueprint/rail-path.ts 按端点表算, 不手摆
- 关联: logistics-choice.md P-logi-09/16; P-style-09 (高架让路口不再需要联锁)
- 流派: 火车网 (本条)
- 出处: ER22 (论坛 p=475458 约 2021, 3, 可能过时); T4、T5、T1 (wiki 信号教程 https://wiki.factorio.com/Tutorial:Train_signals 2023-02-03, 2, 可能过时); T2 (同 + 论坛管理员 2025-03, 2/3); ML11 (同 wiki, 2); T6 (FFF #377 + wiki 2026-10, 2)
- 状态: 待核实
- 沙盘怎么比: 十字路口 + T 字路口各一, A = 全常规信号, B = 联锁进常规出; 8 列车跑 1 小时数死锁; 另比平面路口 vs 立交 (P-style-09)

### P-style-05 机器人基地: 只在短距离高吞吐处划算, 网要小而凸; 乱了就重建成黑盒 + 火车
- 情况: 白瓶以后 (有蓝箱), 超市、研究区、车站内部、雷神星起步
- 做法: 机器人适合车站内部这种短距离高吞吐 (L11); 网小而凸, 大而凹的网机器人扎堆延误 (L12); 雷神星起步常用机器人基地 (F7 顺序: 避雷针 + 回收机 → 电网 → 第一个自动化工厂 → 石油链 → 换成机器人基地 → 粉瓶 → 火箭), 后期 AVADII 改用火车 + 高架、拆掉起始岛 (F22); B 站"百万瓶工厂"推翻杂乱的机器人工厂, 矿岛做成紧凑小黑盒出 4 条满绿带混料 (F23)

- 代价 / 不适用: 玄冥星机器人耗电 ×5 只做小网 (A28); 雷神星机器人挨雷 (L26); 句芒易腐品不走机器人 (G15); 车站两头同网的坑 (logistics-choice.md P-logi-02)

- 出处: L11 (wiki 2026-01-18, 2); L12 (论坛 2025-01, 3); F7 (视频 Rkadindoubt 2026-06-08, 4); F22 (视频 AVADII 2026-08、2026-10, 4); F23 (B 站视频 2026-02-12, 4); ML27 (FFF #421 2024-07-26, 2); L8 (wiki 2026-03, 2); A28 (Steam 2025-01, 3)

### P-style-06 寿司带 (混料回路): 雷神星的默认流派, 平台的环形带; 要有出口和"够了就停"
- 情况: 雷神星废料产物 (12 种)、太空平台星块、品质混杂线
- 做法: 混料走一条回路, 沿路用过滤分流器/过滤机械臂取需要的, 回路末端接回收机销毁或接回起点 (F22 起步岛"混料走寿司带回路自动回收"); wiki: 三个分流器能把混料带上的一种物品拆干净 (F9); 平台: 星块堆叠只有 1, 别存进枢纽, 走环形传送带, 多余的用机械臂扔出平台 (S17); 需要"够了就停"的输入控制 (F10: 粉瓶过剩时电路停投废料)

- 代价 / 不适用: 寿司带塞满就全堵 (SA17 列为平台翻车原因之一); 吞吐 = 一条带 (堆叠超速 240/秒); 2.1 废料共享概率 (一个废料最多出一种) 让回路里的比例更稳但算法要改 (F19)

### P-style-07 直塞 (机器直接喂机器): 句芒的主流, 祝融浇铸、大型采矿机直喂铸造厂, 平台的最小闭环
- 情况: 易腐品; 流体中间品; 空间紧的平台
- 做法: 句芒: 易腐品直塞或走短带, 不囤 (L22); 祝融: 大型采矿机直接喂铸造厂不走矿带 (V23), 铸造厂就地浇铸齿轮/铜缆/钢材 (V19); 平台: 金属星块 → 破碎机 → 铁矿 → 电炉 → 标准弹匣的最小闭环 (S16); 用铸造厂造铸造厂 (2 份材料出 3 台, V22), 用电磁工厂造电磁工厂 (F21)

- 代价 / 不适用: 一台停全停 (句芒断粮要三道保险, planets.md P-planet-13); 机械臂速度是上限: 电力机械臂箱到箱 0.86/秒、高速 2.5/秒、加长 1.25/秒 (facts inserters.chest-to-chest.* ✅), 高倍率机器直塞要堆叠机械臂

### P-style-08 黑盒 / 一图流: 以一条满载堆叠超速传送带 (14400/分钟) 为标准单元, 外部只接原矿; 玄冥的一图流要分段拍
- 情况: 中后期按"单元"复制; 中文社区常见
- 做法: 一条满载堆叠超速传送带 14400/分钟当标准单元, 每种科技包一条带; 新地星 6 色瓶"原矿黑盒"外部只接铁矿 4 带、铜矿 2 带、石矿 9 带、煤 3 带、原油和水各 1 管、少量方解石 (机器人补) (P7); 雷神矿岛做成紧凑"小黑盒"出几条满带混料 (F23); 玄冥星"一键基地"要和浮冰平台蓝图分开拍, 一起开氨溶液不够 (A21); 整张蓝图一次拍下缺热断电, 按发电 → 发热 → 产锂 → 产瓶分段 (A13)

### P-style-09 2.0 高架铁路对流派的影响: 只当主干/过街桥, 车站必须在地面; 立交路口不需要联锁信号; 四套网格
- 情况: 研究了高架铁路 (紫瓶即可, 不必先上太空, T10) 以后
- 做法: 高架只有"地面 + 高架"两层, 完全立交的路口没有平面交叉, 不需要联锁信号, 常规信号可以放得很密, 吞吐大增, 但占地大; T 字路口里把冲突的那条用斜坡绕上去就很有用 (T7, ML9); 车站不能放在高架上 (信号可以) (ML10); 高架下不能放远程输电塔、物流接驳站、炼油厂、机器人指令平台、火箭发射井、农业塔、避雷针、闪电捕捉器; 接驳扩展仓 2.1.7 起可放高架下但收不到货舱 (T9, ML10); 斜坡 16 格长 4 格宽, 顶端不能直接接弯 (T11); 地面铁路蓝图没法自动转高架, 要按位置补支架 (T12); 高架用自己的 2×2 网格, 和地面不重合, 共四套网格 (ML12)

- 做法 (按顺序判断):
  1. 能顺地形绕、绕路不长 → 绕路 (最便宜, 不留后患)
  2. **新地星水面**: 研究了高架铁路 (紫瓶) → 用高架: 两头各一个坡道 (长 16 格, 要留引道), 水上每 10 格一个支架 (用脚本一段段建时), 不用填海; 没研究、水又窄 (几格) → 填海 (50 石头填 1 格, 铁路占 2 格宽)
  3. **祝融星岩浆**: 支架立不了岩浆 (岩浆地块带"铁路"碰撞层), 只能两岸立支架 / 放坡道: 只从一边接最多跨 10 格, **两岸同时往中间接最多 18 格** (20 格接不上); 更宽 → 绕路、借岩浆里的岩石岛, 或等后期能填岩浆
  4. **雷神星油海**: 浅油海直接立支架; **深油海先研究"支架地基"**, 否则立不了
  4b. **玄冥星氨海 (两种都算) / 碎冰、句芒星沼泽**: 支架直接立, 不用研究、不用填海; 这些地块上地面铁路建不了 (facts elevated.aquilo.supports-on-ammonia-ocean ✅、elevated.gleba.supports-on-marsh ✅; 模组 Better Aquilo 说明里"深氨海不能直接建"在原版不成立)
  5. **两条铁路交叉**: 一条走高架 = 立交, 没有平面冲突, 不需要联锁信号 (P-style-09); 平交路口要联锁进、常规出
  6. **高架上不能建车站** (车站一律在地面), 两种信号都能放; 高架下面不能放高建筑 (远程输电塔、货运着陆平台、炼油厂、机器人指令平台、火箭发射井、农业塔、货舱、避雷针、闪电捕捉器)
- 为什么: 填海按格数线性花费、永久改地形, 30 格宽的水 = 约 60 块填海 = 3000 石头; 高架的花费和跨度关系小 (支架 20 钢筋混凝土 + 10 钢板, 坡道 100 钢筋混凝土 + 8 铁轨 + 10 钢板); 岩浆和深油海前期根本填不了, 只能架桥或绕
- 代价 / 不适用: 要钢筋混凝土 (中期); 坡道 16 格长, 两头都要留直线引道; 岩浆宽于 18 格架不过去; 高架下的空间不能放高建筑; 玄冥星氨海这条还没测 (氨海地块没有"铁路"层, 支架应能立, 待核)
- 实现 (脚本 / 机器人摆放): 地面轨 → 上坡道 (朝向 = 行进方向) → 高架直轨一段段接, 接不上就在当前尽头的轨下放支架 → 下坡道 (朝向相反) → 地面轨; 每块按玩家规则 (manual) 查; 高架上的信号用 create_entity 带 rail_layer = elevated (can_place_entity 没这个参数, 永远按地面查); 积木 `experiments/elevated.ts` 的 BRIDGE

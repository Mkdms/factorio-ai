### P-planet-02 新地星围着污染云建防线、围着矿区建铁路; 最怕 2.1 的扩张巢落进污染云; 异虫卵和生物研究中心只能在这里

- 为什么: 进攻只来自吸到污染的虫巢 (D1); 进化按星球分开算 (D1); 太空时代把蓝箱/紫箱/绿箱改成要白瓶 (N6)

## 祝融星

### P-planet-04 祝融星落地: 挖火山岩拿钨 → 组装机小作坊做碳化钨 → 约 5 座铸造厂 → 大型采矿机 → 钨矿 → 橙瓶
- 情况: 第一次到祝融星 (带了建设机器人、润滑油桶、贫铀弹匣、中型电线杆和核能科技, S3)
- 做法: 先用组装机搭小作坊, 手挖火山岩 (巨型火山岩出 3~15 钨矿和几十个铁铜石) 做碳化钨 (碳化钨只能在组装机2/3型做, 铸造厂做不了) → 约 5 座铸造厂 → 大型采矿机 → 开出第一片钨矿 → 补全冶金科技包（橙瓶）和火箭 (S5, V3, V7, V9); 早期不需要钨矿采矿机, 手挖岩石够造前几台铸造厂 (V3); 用铸造厂造铸造厂, 2 份材料出 3 台 (V22)
- 为什么: 触发链: 挖方解石 → 方解石加工; 挖火山岩/撼地虫残骸 → 碳化钨; 造碳化钨 → 铸造厂; 造铸造厂 → 大型采矿机; 造大型采矿机 → 钨钢; 造钨板 → 橙瓶 (本机); 钨矿多在撼地虫领地 (S5), 只有大型采矿机能采 (V1)
- 代价 / 不适用: 空手去也能起步但前几小时很慢, 发帖人带错了东西 (炼油厂、抽油机 — 祝融没原油) (V4); 没研究中型电线杆会卡住 (没木头) (S3)
- 关联: progression.md P-prog-07; defense.md P-def-13 (什么时候打撼地虫)
- 流派: 直塞 (小作坊) → 铸造厂 + 管道
- 出处: S5 (论坛 p=685677 2025-11 ~ 12 + wiki, 3/2); V3 (论坛 2025-11-30, 3); V7 (视频 UnjustOdin 2026-08-04, 4); V9 (B 站专栏 cv41680986 2025-05-15, 3); V22 (论坛 2025-12 + wiki 2026-09, 3/2); V4 (论坛 2024-11、2025-11 + Reddit 摘要, 3); S3 (论坛 2025-11 + wiki, 3/2); 本机 technology.lua (1)
- 状态: 待核实
- 沙盘怎么比: 按清单落地, 记录到第一座铸造厂、第一台大型采矿机、第一瓶橙瓶的时间; 对照组不带机器人

### P-planet-05 祝融星围着灰烬高原建厂、围着岩浆和方解石建铸造厂; 真正的瓶颈是方解石和水, 石矿要有出口
- 情况: 祝融星选址和产线
- 做法: 三种地形: 灰烬高原 (悬崖岩浆少、有煤, 最适合建厂)、岩浆盆地 (钨矿, 只能大型采矿机)、火山山地 (硫酸喷泉和方解石) (V1); 铁铜几乎全来自岩浆 + 方解石 (500 岩浆 + 1 方解石 → 250 熔融铁 + 10 石矿), 岩浆无限但方解石有限 → 方解石是真正瓶颈 (V10); 水只能靠酸中和 → 蒸汽冷凝 (1000 蒸汽 → 90 水), 用水的产线都受此限制 (V2); 石矿副产品 (熔融铜出得更多) 倒进岩浆或做填埋材料/石砖/混凝土 (V15); 石油: 先简易煤炭液化 (煤 + 方解石 + 硫酸 → 重油) 攒重油, 有橙瓶后换正规煤炭液化 (不用方解石) (V20); 煤和钨是有限矿, 大基地提前占大煤矿 (V24)
- 为什么: 没有原油、没有水源; 配方都要方解石 (熔融金属、酸中和、简易煤液化、高级推进剂)
- 代价 / 不适用: 地下传送带/地下管道穿不过岩浆, 蓝图静默失败 (V18); 岩浆只能用工程基座 (靛瓶) 填 (V18); 悬崖到处都是, 研究悬崖炸药 (祝融解锁) 或高架后才好建 (V1); "1 方解石 = 750 块铁板"是错的, 本机约 112 块 (V14)
- 关联: progression.md P-prog-10 (电); logistics-choice.md P-logi-06/12; production.md P-prod-20
- 流派: 铸造厂 + 管道 (直塞) / 黑盒
- 出处: V1 (wiki 祝融星 2026-06-30 + 论坛 2025 ~ 2026, 2/3); V10 (论坛 Tertius 2025-12 + wiki, 3/2); V2 (wiki + 论坛 2025-02, 2/3); V15 (Steam 2024-10 ~ 11 + wiki 岩浆 2026-02, 3/2); V20 (wiki + 视频 2024-11, 2/4); V24 (视频 AVADII 2026-07, 4); V18 (wiki + 论坛 2026, 2/3); V14 (Reddit 摘要 2025-01 vs 本机, 3/1)
- 状态: 待核实 (计算器要把"水来自酸中和"和方解石消耗算进去)
- 沙盘怎么比: 10 台铸造厂浇铸铁板, A = 石矿出口到岩浆 (堆叠机械臂), B = 无出口; 看停机; 顺带量 2.1.9 后一个堆叠机械臂每秒能往岩浆倒多少 (V16 过时)

### P-planet-07 祝融星最怕的不是撼地虫而是惊动它: 不打也能发展, 要钨矿或要地才清, 先清出生区旁的小型; 出口是铸造厂、大型采矿机、超速传送带、橙瓶和重炮
- 情况: 祝融星扩张决策
- 做法: 每块领地一只撼地虫, 只在生成地图时出现, 领地像泰森多边形紧挨着, 出生区 (半径约 224 格) 不属于任何领地; 不招惹时沿边界巡逻, 在领地里建东西它直冲建筑; 杀掉后领地永久空出, 邻居不扩过来 (V26); 只有建筑会惊动它 (2.0.14 修了车辆惊动), 开车穿过安全 (V28); 转弯半径大偶尔走出领地, 凹形领地更容易 (V27) → 建筑离边界留余量; 决策: 不打也能发展 (出生区 + 领地外), 只有要在钨矿上放采矿机或要扩地方时才杀 (V29); 小型离出生点近 (约 720 格内)、中型 720 ~ 1296、大型更远 (本机公式, V31) → 先清出生区旁的小型; 原子弹会炸出岩浆坑, 只能用工程基座填 (V30)。只能在祝融造: 橙瓶、铸造厂、大型采矿机、超速传送带系列、酸中和; 在祝融解锁但别处能造: 重炮、煤炭液化、悬崖炸药、速度插件 3 (V6)
- 为什么: 撼地虫 3 万 / 10 万 / 30 万血, 火/激光/冲击 100% 免疫, 自愈每 tick 40 / 130 / 400 (EL4); 没有污染和进化, 威胁是静态的
- 代价 / 不适用: "开车进领地吵醒它"是 2.0.14 前的说法 (V28); 2.0.42 起它能摧毁打开的闸门 (V28); 有人认为打虫是这颗星必要的关卡 (V29)
- 关联: defense.md P-def-13 (怎么打); 读取层要能读领地边界 (V26); 调度器把领地当危险区 (lessons #11)
- 流派: 通用
- 出处: V26 (wiki 祝融星 2026-06-30, 2); V28 (本机更新日志 2.0.14/2.0.18/2.0.42, 1); V27 (论坛官方员工 2024-10 ~ 11, 2); V29 (论坛 2024-11 ~ 2026-06, 3); V31 (本机 planet-vulcanus-map-gen.lua + 论坛, 1/3); V30 (本机更新日志 2.0.44, 1); V6 (wiki 2026-06-30, 2); EL4 (本机原型, 1)
- 状态: 待核实 (领地距离分档、建筑离边界余量要测)

### P-planet-08 雷神星落地: 先找小岛上的雷神地宫废墟触发回收, 再找大岛建厂; 空手也能活

- 做法: 岛分三种: 小岛有雷神地宫废墟和最密的废料堆, 中岛多小废墟和小废料堆, 大岛主要是雷击石、废墟少 → 采矿在小岛中岛, 建厂找大岛 (F1); 回收科技要手动挖一个雷神地宫废墟才触发 → 落地第一件事找地宫 (F3); 起步顺序: 准备平台 → 找大岛 → 避雷针和回收机 → 电网 → 第一个自动化工厂 → 石油链 → 机器人基地 → 基础工厂和粉瓶 → 火箭 (F7); 空手也能: 拆废墟凑第一根避雷针, 固体燃料 + 石炉起步, 2.0.11 起废墟掉铁棒能造电线杆 (F4); 很多东西可以直接手搓, 不太需要分段建设 (F5)
- 为什么: 雷神星是最简单的外星, 没有敌人, 唯一考验是混料处理 (F5)
- 代价 / 不适用: 深油海里人走得很慢 (F1); 没带物流接驳站落地、平台受损的案例 (F4); 2.1.13 起废墟能被"仅树木/石头"的拆除规划器选中, 机器人拆地宫算不算"挖"待测 (F33)

## 玄冥星

### P-planet-16 玄冥星落地: 太阳能起步 → 供热塔 + 换热器 + 汽轮机 → 热管 → 浮冰平台 → 锂/氟酮 → 靛瓶; 分段拍, 全靠外运

### P-planet-17 玄冥星围着供热塔建: 发电贴着塔、保温放另一侧、整块复制; 热管不能走地下, 传送带/管道/热管三者抢路
- 情况: 玄冥星布局
- 做法: 只有换热器需要约 500 度, 供热塔紧挨换热器, 换热器和汽轮机集中在塔一侧, 新接入的冷建筑放另一侧, 扩建时不会把发电抢冷; 要扩就整块复制这个模块 (A12); 热源 > 30 度就能让相邻 (含斜对角) 建筑解冻, 热管本身不向环境散热 (A6); 热管不能走地下、不能从冰下穿过, 传送带和管道要绕开热管 (地下传送带 50kW、地下管道 150kW 比地面贵得多) (A7, S8); 保温负荷经验值: 平均每格约 40kW, 一座 40MW 供热塔约带 1000 格或约 200 个极速地下传送带, 每约 30MW 需求配一座再多建一倍 (A9); 热管链离热源最多约 969 格 (相邻至少差 1 度) (A10); 远端 450 度也够保温但换热器要 500 → 发电必须贴塔 (A11)

### P-planet-18 玄冥星最怕"热 → 水 → 电"连锁和两个回路卡死: 氨/冰要有出口, 氟酮热侧留空
- 情况: 玄冥星运行期
- 做法: ① 氨: 每块浮冰平台净多 100 氨, 氨必须有出口 (烧成固体燃料/火箭燃料, 或按库存切配方), 否则氨罐满 → 分离线停 → 融冰缺水 (A20); 用核电也要"氨 → 固体燃料"排放口 (A22); 多余的冰两台面对面回收机互相销毁 (A20); 储罐快满用程控扬声器报警, 给氨多放约 20 个储液罐缓冲 (A22); ② 氟酮: 最常见卡死是冷氟酮储罐满 → 冷却停 → 热氟酮没人消耗 → 造热氟酮的机器也堵; 解法不是销毁冷氟酮, 而是给热氟酮加储液罐, 把造热氟酮的低温工厂启用条件设成 热氟酮 < 15000 (A24); 聚变回路: 冷却配方一次放 10 单位, 冷侧剩余空间 < 10 就停、整个回路卡死, 让热侧尽量空、别往回路加桶装氟酮 (A25); 冷却剂配方只还回一半热氟酮, 要持续补新氟酮 (A23); ③ 断电恢复工具箱: 蓄电器经电闸接主网平时充满断电合闸; 几块太阳能给关键区; 储液罐存 500 度蒸汽 (一罐 ≈ 485 个蓄电器); 固体燃料只在热量低于约 900 度才送 (A16)
- 为什么: 没有敌人 (原计划的水母敌人砍掉, A29), 危险全是物理连锁; 每一环都是"输出满 → 停"的同一类问题 (lessons #7)
- 代价 / 不适用: 2.1 起管道也能读液量, 可以不放储液罐 (A24); "一台化工厂火箭燃料够 3 座供热塔"和本机推算 (约 1.5 座) 对不上 (A17)
- 关联: logistics-choice.md P-logi-12; production.md P-prod-15/20; 调度器把"热"算进"电"那一档
- 流派: 通用
- 出处: A20 (Steam 2025-01-20, 3; 本机配方推算一致, 1); A22、A16 (Steam 2025-01-20, 3); A24 (论坛 2026-01, 3); A25 (论坛 2025-11, 3); A23 (wiki 热氟酮 2026-10-06, 2); A29 (wiki + FFF #432, 2); A17 (Reddit 摘要 2024-12 vs 本机推算, 3/1)
- 状态: 待核实 (评测场"氟酮回路不卡死")

### P-planet-19 玄冥星出口是靛瓶、低温工厂、聚变反应堆/发电机、桶装氟酮; 量子处理器可以搬到平台做; 聚变比例按 2.1.24 重测

### P-planet-20 离开新地星前先"遥控一小时": 只用地图视图运营, 暴露自动化缺口再走
- 情况: 第一次要离开新地星, 防线和物流看着能转
- 做法: 离开前约一小时不亲自走动、不手搓, 只用地图视图查物流、制造、防御是否自己转; 另备几辆坦克, 离开后可遥控驾驶救急
- 为什么: 离开后能做的只有远程下单和遥控; 手搓和手补会掩盖缺口 (PB-N1, N6)
- 代价 / 不适用: 多花一小时; 防线在 2.1 扩张规则下仍可能被新巢打破, 遥控一小时只是下限

### P-planet-21 出发清单: 机器人工厂 + 发射井 + 备用火箭 + 电动机 + 起步物资
- 情况: 准备首发祝融星 (或任意外星)
- 做法: 机器人小工厂 (组装机、箱子、机械臂、电线杆、机器人指令平台、物流/建设机器人) 能远程下单; 每个新星球的发射井和至少一枚火箭的材料; 约十枚火箭材料作备份; 电动机成批备好 (有人每次带 250) 并建好电动机生产线; 火箭燃料、塑料等本地难做的东西先送; 传送带、熔炉、组装机、化工厂等起步物资
- 为什么: 新星球从零起步, 缺的往往是机器人和火箭部件; 电动机是机器人和火箭仓共同瓶颈 (PB-N2, N3, N4, N8, N14)

### P-planet-67 高爆泡泡: 被拆、被打都会爆, 清地前先看周围有没有自己的东西
- 情况: 句芒星清地建基地、推防线, 地上长着高爆泡泡 (句芒植物)
- 做法: 8 格内有己方建筑的先不清; 要清时人离 6 格以外, 用拆除规划标记交给建设机器人逐棵拆, 不要手挖; 炮塔推进时别让炮塔和泡泡挤在一起 (打到泡泡也会爆); 大片泡泡留到炮塔和建筑就位前先清
- 为什么: 原型里高爆泡泡是"树"类, 50 血; 被打死和被挖掉都会生成"高爆泡泡爆炸", 向周围 3 ± 2 格抛 5 颗种子, 每颗落地在半径 4 内造成 5 点爆炸伤害; 第一版联机时看到成片连锁, 手清时炸毁过建筑和箱子
- 代价 / 不适用: 原型伤害看着很小 (每颗 5 点), 和第一版"炸毁建筑"的观察对不上 → 也可能是连锁次数多或种子落地后的效果没读到, 要沙盘弄清再定安全距离; 交给机器人拆, 机器人也可能被炸
- 关联: P-planet-12 (落地顺序); P-planet-68 (地块和农场施工); defense.md P-def-11 (句芒防线)
- 流派: 通用
- 出处: 第一版知识库 topics/new-base-build-ops.md (2026-10-30, 未核实, 联机观察); 本机原型导出 2.1.24 (tree: boompuff、explosion: boompuff-explosion、projectile: boompuff-seed; 2026-11-02 清点时抽查), 1; research/players/v1-knowledge.md V1K-14
- 状态: 部分核实 (facts v1.boompuff-explodes-on-death ✅: 被打死和脚本挖掉都会爆, 但伤害小 —— 木箱 2 格 -10~-15、8 格 0, 挨着的泡泡不连锁; "8 格内先不清"偏保守, 主要防的是成片清理时多次叠加)
- 沙盘怎么比: 一片高爆泡泡旁 2 / 4 / 8 格各放一个木箱和一台组装机2型; A = 玩家手挖一棵, B = 建设机器人拆一棵, C = 机枪炮塔打一棵; 记爆炸次数、有没有连锁、己方掉血

### P-planet-68 句芒地块和农场施工: 哪里能走、能建、能填, 农业塔的种植格里不能有任何东西
- 情况: 句芒星选址、铺路、建农场
- 做法: 各种沼泽 / 湿地人能走 (走得慢)、不能直接建, 铺填埋材料后能建, 抽取泵能从湿地抽水; 深湖人走不过去, 也能填; 填埋材料能铺的句芒地块是全部沼泽 / 湿地加深湖 (红珊瑚沼泽也能填, 第一版一度以为不能); 人造土只能铺在同色湿地上 (玉玛果人造土 → 玉玛果湿地, 果冻果人造土 → 果冻果湿地), 沃土要异虫卵 (facts gleba.overgrowth-soil.needs-biter-eggs ✅); 农业塔周围 7×7 个 3×3 种植格, 每格整格都要可种、不能有任何实体 (电线杆、机械臂、传送带都不行), 按种植格的网格整格铺土、整格留空; 在旧农业塔范围里建东西, 塔会在新建筑位置反复补种 → 先放幽灵清掉植株, 再立刻放实物
- 为什么: 原型碰撞层: 沼泽 / 湿地是"浅水" (water_tile + resource + floor, 没有 player 层, 走速 ×0.8), 深湖多一个 player 层; 填埋材料的可放地块清单里列了全部沼泽 / 湿地和深湖; 农业塔种植半径 3 (按 3×3 格算)
- 代价 / 不适用: 填海费石矿 (一个填埋材料 50 石矿), 大片填要分期、只填必要的格; 高架铁路跨沼泽不用填 (facts elevated.gleba.supports-on-marsh ✅), 但铁路斜坡低端要落在实地上 (V1K-36, 待核实)

# 老玩家的思维方式 (思路库)

> 2026-11-01 第四轮检索提炼。出处里的 M 编号指 `docs/research/players/mindset.md`。思路不是事实: 全部"待核实", 分歧的并列写、不裁判。视频来源只凭标题/简介/章节。格式见 [README.md](README.md)。

### P-mind-01 现在该干什么: 先找当前最卡的那一个
- 情况: 任何阶段, 尤其蓝瓶之后一堆线同时缺料时
- 做法: 不追求"没有瓶颈", 每次只处理当前卡住产出的一个; 先问它是真缺产能、还是缺电、缺上游原料、缺出口
- 为什么: 老手的共识是"总有东西在卡"; 蓝瓶"墙"常常是上游 (先进电路板、石油) 而不是蓝瓶组装机
- 代价 / 不适用: 同时有多个瓶颈互相依赖 (电 + 铜) 时要先解依赖链的根
- 关联: P-mind-02 (提前缓存)、P-mind-04 (倒推)、第一版教训 #8 (想法先后不等于优先级)
- 流派: 通用
- 出处: M1, M2 (官方论坛 Building Phases, 2015, 可信度 3); M3
- 状态: 待核实
- 沙盘怎么比: 调度器 A 按"想法先后"排任务 vs B 按"当前最卡资源"排任务, 看到达火箭的总时间

### P-mind-02 先认出三个会卡死全局的节点, 并提前缓存
- 情况: 开局到火箭; 速通或要求稳定无人值守时
- 做法: 把目标拆成"完整的绿瓶自动线 (含实验室)"、"石油化工区"、"电 + 铜 + 速度/产能插件 + 蓝板 + 电动机 + 轻质框架的大规模生产和缓存"三个节点; 第三个最容易在火箭零件阶段短缺, 要提前做并存起来; 轻质框架火箭和金瓶都要
- 为什么: 作者的结论是难点不是"紧凑", 而是"不知道什么时间点该做什么"
- 代价 / 不适用: 数量是 1.x 的 (可能过时), 只借"提前缓存后期必缺的几样"的思路; 太空时代的必缺清单要重列
- 关联: P-mind-03 (去新星球前清单)
- 流派: 速通式
- 出处: M3 (B 站专栏 cv4356063, 2020-01, 可信度 3)
- 状态: 待核实
- 沙盘怎么比: 有缓存 vs 到时再做, 看火箭发射井和火箭零件阶段的停顿时间

### P-mind-03 离开新地星前: 电力、机器人、防御三件事
- 情况: 第一次出发去新星球前
- 做法: 先解决落地后的电力 (雷神星带避雷针原料、广域配电器、蓄电器; 祝融星带太阳能板和蓄电器; 句芒星先靠火箭燃料或果实走供热塔, 机械臂读温度启停); 带一组建设机器人; 先把新地星防住, 免得你不在时变虫子食物
- 为什么: 落地后没电什么都不转; 机器人是"很多人忘了带"的东西; 新地星污染会在你离开时继续引虫
- 代价 / 不适用: 作者的方案来自 2.0 首月, 细节可能过时; 供热塔数值以本机为准
- 关联: P-mind-11 (新星球先解决电)、defense 里"先防线后工厂"
- 流派: 通用
- 出处: M10 (B 站专栏 cv39601374, 2024-10, 3); M11 (视频标题章节, 4); M31
- 状态: 待核实
- 沙盘怎么比: 每个星球的"落地包"清单 A (含防御和机器人) vs B (不含), 看落地后 30 分钟是否自立

### P-mind-04 目标倒推, 不按科技树顺序点
- 情况: 研究队列决策
- 做法: 先选一个中期目标科技, 再往回查前置和需要的瓶子; 每档有一条通往下一种瓶子的主路径
- 为什么: 按顺序点会点到暂时用不上的科技, 又缺关键的
- 代价 / 不适用: 目标选错会浪费; 太空时代部分科技受"发现星球"和触发条件限制
- 关联: P-mind-01、requirements"研究自动续上"
- 流派: 通用
- 出处: M4 (仅摘要, 3); M49 (触发式科技, FFF-376, 2)
- 状态: 待核实
- 沙盘怎么比: 倒推队列 vs 默认顺序, 到第一个目标的时间

### P-mind-05 重构: 先建新的再拆旧的
- 情况: 中局发现布局不行、想大改时
- 做法: 在旁边建新的子工厂, 新的跑通后旧的才拆; 旧基地继续给新建供零件, 过渡期不停产; 一次全拆只适合"为了学习"
- 为什么: 全拆让工厂停摆、连传送带都做不出
- 代价 / 不适用: 地盘不够并行建时, 先按色/按产物一块块迁
- 关联: P-mind-06 (重来 vs 修)、第一版教训 #8
- 流派: 通用
- 出处: M7 (官方论坛 2022-09, 3); M8
- 状态: 待核实
- 沙盘怎么比: 迁移任务的"总停产时间", 并行建 vs 直接拆

### P-mind-06 重来还是修: 老手之间有分歧 (并列)
- 情况: 基地已经乱了
- 做法 A: "频繁重开, 别想救一个乱掉的基地", 学到的原则马上用, 做得更快
- 做法 B: 保留起始基地当材料来源, 边用边迁; "每次乱了就重开就永远做不出巨型基地"
- 为什么: A 看重学习速度和干净; B 看重已积累的产能和不停产
- 代价 / 不适用: 我们的世界是用户存档/服务器, 一般不能重开, 偏向 B
- 关联: P-mind-05
- 流派: 通用
- 出处: M8, M32 (Steam 2024-11, 3)
- 状态: 待核实
- 沙盘怎么比: 同一个乱掉的基地, 迁移 vs 重建的资源和时间

### P-mind-07 留 3 倍空间, 生产线朝向要能复制
- 情况: 布局设计时
- 做法: 预留的空间是以为需要的 3 倍; 方向统一, 复制粘贴扩展不撞邻居; 地面上留增长缓冲
- 为什么: 新手不知道后期要什么, 之后一定会用上这块空地
- 代价 / 不适用: 平台上空间是有限的 (见 P-mind-08)
- 关联: P-mind-19 (参数化蓝图)、第一版教训 #8 (外壳先建会占地)
- 流派: 通用
- 出处: M14 (Steam 2024-10 / 11, 3); M21
- 状态: 待核实
- 沙盘怎么比: 布局生成器带预留带 vs 不带, 看后期扩建是否要拆

### P-mind-08 紧凑只在太空平台上是美德
- 情况: 平台设计 vs 地面设计
- 做法: 平台上面积有限、要紧凑; 地面上不要紧凑到无法增长; 2.1.21 后平台速度由重量决定, 不迷信窄船
- 为什么: 开发者就是想要"有限空间里的迷你工厂" (平台不能有洞); 他们想鼓励多样船型和紧凑设计、阻止铅笔船和堆推进器
- 代价 / 不适用: 平台要补给时的货物空间和重量要一起算
- 关联: space-platforms-advanced.md
- 流派: 太空平台
- 出处: M15 (Steam 2024-11, 3); M50 (FFF-382, 2); M58 (FFF-448, 2026-10-09, 2)
- 状态: 待核实
- 沙盘怎么比: 同载货量的窄船 vs 宽船在 2.1.24 的往返时间

### P-mind-09 完成度比完美比率重要, 但太空时代要求新地星先自给
- 情况: 新手期、开局引擎
- 做法: 先跑通整局, 不追完美; 不需要完美比率、火车、逻辑电路也能发射火箭; 但太空时代要你先让新地星自己能转
- 为什么: 起步时建的大多是临时的, 学习靠完成一局; 太空时代内容翻倍, 新地星不自给会拖累所有星球
- 代价 / 不适用: 无人值守目标要求稳定, 不能"做一半"
- 关联: P-mind-01
- 流派: 通用
- 出处: M24, M9 (Steam 2024-10, 3); M33
- 状态: 待核实
- 沙盘怎么比: 开局引擎"能跑的最小版本"到火箭的时间 vs 优化版本

### P-mind-10 先去哪个星球: 三种理由并列
- 情况: 第一次离开新地星
- 做法 A (祝融星): 悬崖炸药让以后每个星球好扩张, 铸造厂 + 大型采矿机大幅降低铁铜需求, 重炮清新地星; 2.1 更偏祝融; 成就统计多数先去祝融
- 做法 B (雷神星): 电磁工厂几乎不花时间搭、回收机、机甲和个人机器人平台二型, 回报立即; 有人"只为电磁工厂去"
- 做法 C (句芒星): 堆叠机械臂、更好的实验室、产能 3、高级星岩处理; 认为"不是更难而是不同", 但对新手跳度大、敌人持续骚扰
- 为什么: 三个星球彼此独立, 顺序是"有影响的战略选择" (开发者原话); 取决于敌人和悬崖设置
- 代价 / 不适用: 我们的世界敌人设置不一定, 用户定
- 关联: P-mind-03、P-mind-11
- 流派: 通用
- 出处: M68, M69 (官方论坛 2026-09 ~ 10、2024-11, 3); M47 (FFF-373, 2)
- 状态: 待核实
- 沙盘怎么比: 三种顺序到第一个火箭 + 第一艘平台的资源和时间; 不裁判

### P-mind-11 新星球先解决电
- 情况: 任何新星球落地
- 做法: 先问"落地后怎么发电": 雷神星避雷针 + 蓄电器; 祝融星太阳能强; 句芒星的燃料不能靠木头 (烧得太快), 果实会腐坏, 用火箭燃料 / 供热塔; 供热塔读温度启停
- 为什么: 没电什么都转不起来, 且各星球的电源机制完全不同
- 代价 / 不适用: 玄冥星是"热 → 水 → 电"连锁, 另有规则 (见 aquilo.md)
- 关联: P-mind-03
- 流派: 通用
- 出处: M10, M30
- 状态: 待核实 (供热塔阈值以本机和沙盘为准)
- 沙盘怎么比: 每个星球的落地电力方案, 到"主产线开机"的时间

### P-mind-12 品质: 早投 vs 晚投 (并列)
- 情况: 获得品质科技之后
- 做法 A (晚): 品质是"早期陷阱", 全面传奇要等传奇三级插件在各处可用; 一位玩家花约 30 小时学品质、几乎只用到个人装备
- 做法 B (早, 有限): 早期只做品质太阳能板和蓄电器 (给平台和雷神星供电)、平台件、个人装备; 开发者原话: 平台空间有限, 最好的物品先留给平台
- 为什么: 开发者警告"太早追太多品质"是巨大的陷阱; 品质的目的是延长"平衡几种增长方式"的中期; 2.1 把再处理的品质路线关了, 品质搬到地面
- 代价 / 不适用: 品质每升一档设计要重做 (见 P-mind-13)
- 关联: quality-advanced.md
- 流派: 通用
- 出处: M26, M27, M48, M57
- 状态: 待核实
- 沙盘怎么比: 早期品质太阳能板的回报 vs 同资源投扩产

### P-mind-13 品质只作参数, 不做每档一套设计
- 情况: 设计库、模式库
- 做法: 把品质当参数写进蓝图, 不为每档做一套; 设计时假设"稍后会升品质"; 参数化蓝图里"靠上的条目能被靠下的访问"
- 为什么: 每升一档就重做设计会造成疲劳; 品质和产能让最优设计一直在变
- 代价 / 不适用: 参数化蓝图本身有学习成本
- 关联: P-mind-19
- 流派: 通用
- 出处: M27, M16 (Steam 2024-11、官方论坛 2025-12, 3); M73
- 状态: 待核实
- 沙盘怎么比: 一个参数化模式在不同品质下是否都能跑

### P-mind-14 句芒的腐坏: 保持吞吐, 不要缓冲
- 情况: 句芒星任何产线
- 做法: 传送带保持转动, 直塞、短带、限格子的箱子; 用过滤机械臂或分流器把腐坏品取走, 烧掉发电或做火箭燃料; "接受腐坏只是另一种物流问题"; 扔掉坏果、让线继续转
- 为什么: 开发者说腐坏品必须被当成"临时的", 重要的是吞吐; 最初的设计有约十种植物, 砍到两种是为了找回"造工厂的感觉"
- 代价 / 不适用: 无缓冲意味着上游断供时下游立刻停, 要有自举和备用 (见 gleba.md)
- 关联: P-mind-15, 第一版教训 #6 (自举)
- 流派: 句芒星
- 出处: M28 (摘要, 3); M29, M54 (FFF-414、417, 2)
- 状态: 待核实
- 沙盘怎么比: 有缓冲箱 vs 无缓冲, 看断供一次后恢复时间和腐烂量

### P-mind-15 句芒自己发电, 不依赖进口
- 情况: 句芒星电力
- 做法: 供热塔 + 火箭燃料 + 果实 / 腐坏品, 连续无限的电, 太阳能只做引导; 避免"进口燃料失败整个基地腐坏"
- 为什么: 进口断了的后果是全线腐烂; 开发者的星球设计要求每个星球围绕自己的主问题
- 代价 / 不适用: 供热塔满温照烧要读温度, 阈值不能设在 500 度附近 (见 circuits.md)
- 关联: P-mind-14
- 流派: 句芒星
- 出处: M30 (官方论坛 2025-03, 3); M10
- 状态: 待核实
- 沙盘怎么比: 果实发电的自洽性: 满负荷下燃料够不够

### P-mind-16 运输选型: 距离、量、物品三问
- 情况: 任何要搬东西的决定
- 做法: 传送带=短到中距离的稳定大宗 (约 500 格以内, 粗略); 火车=长距离大宗; 机器人=密集区域的多样低量, 在车站装卸尤其合适, 长距离和大宗差且耗电; 老手最后多数混用
- 为什么: 机器人没有寻路 (直线飞) 且耗电; 传送带可预测; 火车占地且要信号
- 代价 / 不适用: 腐坏品、会孵化的东西不适合机器人
- 关联: logistics-choice.md
- 流派: 通用
- 出处: M71 (wiki, 2); M62 (FFF-374, 2); M39
- 状态: 待核实
- 沙盘怎么比: 同产量不同距离下三种方式的成本 / 失败模式

### P-mind-17 总线 / 城市块 / 混合: 并列
- 情况: 主工厂布局
- 做法 A (总线): 小基地好懂、可预测、"新手支架"; 单侧带肩、精益环保
- 做法 B (城市块): 可复制、巨型基地; 一个星球 N 个块 (如句芒 6 个、玄冥 3 个, 视频标题)
- 做法 C (混合): 核心材料上总线, 子工厂用块; 关键是决定"什么该上线" (中间品上线, 成品进超市)
- 为什么: 总线的批评是带子最多; 城市块的批评是多余路口、"为外观创造"; 模组多了总线难维护
- 代价 / 不适用: 我们没有模组, 但敌人和平台约束不同
- 关联: layout-styles.md
- 流派: 主线 / 城市块 / 混合
- 出处: M72, M46, M38, M64, M13
- 状态: 待核实
- 沙盘怎么比: 同产量的占地、带数、扩建时间; 不裁判

### P-mind-18 寿司带: 少带数换来的代价是堵塞风险
- 情况: 雷神星分拣、实验室喂瓶、低量多品种
- 做法: 一条带混运多种, 用红黄分流器调比例, 取料用分流器链; 尾部必须有销毁口 (岩浆 / 太空 / 回收机 / 回收箱)
- 为什么: 省带数, 少车道; 代价: 任何一种超过一整条带的输入会堵死, 环形容易堵
- 代价 / 不适用: 有腐坏或会孵化的物品不适合
- 关联: 每种产物都要有出口 (第一版 #7 同类)
- 流派: 寿司带 (雷神星常见)
- 出处: M34 (wiki, 2); M35 (视频, 4)
- 状态: 待核实
- 沙盘怎么比: 寿司带 vs 分带, 看堵塞率和带数

### P-mind-19 重复的模式一律做成参数化蓝图 / 黑盒接口
- 情况: 模式库
- 做法: 凡能重复的设计都做蓝图; 每个模块写清输入口 / 输出口 / 吞吐; 对齐变电站网格; "进出"设计原则
- 为什么: 复制扩展不撞、可以平铺; 中文社区的"黑盒"就是固定接口的产线
- 代价 / 不适用: 平铺会占很大一块基础面积; 单一模式灵活性差
- 关联: P-mind-07, P-mind-13
- 流派: 黑盒 / 模块
- 出处: M16, M37, M44, M64
- 状态: 待核实
- 沙盘怎么比: 模块拼接后的实际吞吐 vs 单模块标称

### P-mind-20 直塞: 缩短链条, 但整局直塞是一种挑战
- 情况: 高内聚的小链条; 或"火车直插"挑战
- 做法: 机械臂直接送到下一台机器, 省带和箱子; "火车直插"挑战连带和机器人都不用
- 为什么: 链短、占地小、UPS 友好 (有争议); 极端版代价: 插件塔受限、长臂慢、列车要精确配平、工厂只在供货车在站时才转

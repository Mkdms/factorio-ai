### P-prog-01 新地星从落地到火箭分六段, 每段只做让下一段开工的事
- 情况: 新地星开局 (太空时代, 2.0 起多数早期科技是触发式, 不花科技包)
- 做法: ① 热能段: 采含煤岩石拿煤、手搓队列不停、1 锅炉配 2 蒸汽机、做 50 铁板/10 铜板触发蒸汽动力和基础电学; ② 电 + 红瓶段: 造研究中心触发机自科技包（红瓶）, 研究电力采矿机 (2.0 起要研究), 48 石炉喂满一条基础传送带; ③ 绿瓶 + 超市段: 边用边建建材超市; ④ 石油 + 蓝瓶段: 采到原油触发基础原油处理, 蓝瓶后优先扩超市并上机器人产线; ⑤ 火箭段: 太空时代的火箭发射井蓝瓶阶段就能研究, 每枚火箭只要 50 个火箭组件 (1 处理器 + 1 轻质框架 + 1 火箭燃料 各一); ⑥ 白瓶段: 一个停在轨道的小平台做太空科技包（白瓶）, 之后才有物流系统 (蓝箱/绿箱/紫箱)
- 为什么: 2.0 把热能阶段拉长、把电力采矿机放进研究, 老玩家认为是"逼你升级"(N3); 火箭比原版早且便宜, 但真正去别的星球要发几十枚火箭 (N5); 蓝箱要白瓶, 白瓶以前机器人只能当建设用 (N6)
- 代价 / 不适用: 死亡世界或 600% 虫巢设置下顺序改成"尽快上天, 打不过就躲"(N26, 视频); 高虫设置下第 ②③ 段要并入军事 (见 P-prog-16)
- 关联: 第 ⑥ 段决定补弹方式 (defense.md P-def-08: 白瓶前只能传送带 + 机械臂或激光炮塔); 第 ④ 段的机器人决定能不能"无人自保"(P-prog-18); 第 ⑤ 段的火箭发射井每颗星都要就地再造一座 (S23)
- 流派: 通用
- 出处: N1 (B 站专栏 cv44924884, 2026-01-21, 3); N2 (同上 + cv41557560, 2025-05-05, 3); N3 (论坛 p=675527, 2025-06, 3); N5 (Reddit 摘要 2025-01-27, 3); N6 (Steam 2024-10-21 + Reddit 摘要, 3); N22 (B 站专栏 cv41650857, 2025-05-13, 3); 本机触发科技表 (nauvis.md 第 1 节, 1)
- 状态: 待核实 (facts: smelting.stone-furnace.rate 已核实 48 石炉 = 一条基础传送带)
- 沙盘怎么比: A = 按六段顺序跑开局引擎, B = 先铺大主线再补电; 看到第一枚火箭的游戏时间和中途停产次数

### P-prog-02 "先小后大": 新地星第一版做小, 外星建筑到手再整体重建
- 情况: 新地星从红瓶到第一次出发; 用户是新手、想少走弯路
- 做法: 新地星第一版只做能上天的小基地 (每分钟 30~75 瓶), 不铺大主线、不追比例; 等拿到铸造厂、电磁工厂、大型采矿机后再整体重建 (冶炼搬进铸造厂, 电路板搬进电磁工厂); 三颗内圈星球都去过以后再造大船和超大基地
- 为什么: 外星建筑自带 +50% 产能、速度 2~4 倍, 新地星早期的组装机线迟早被替换 (N9); 第一版教训 #8 就是"每提一个想法就加进同一张大图, 外壳先建、核心一台没有"
- 代价 / 不适用: 重建要停产, 所以"做小"不等于"做烂": 要留 3 倍预想的空间 (N4), 重建时先建新再拆旧; 是否真的换铸造厂有分歧 (见 P-prog-12)
- 关联: 决定了布局流派 (layout-styles.md P-style-01: 新地星第一版用小主线或意大利面, 不急着城市块); 决定了插件投入 (production.md P-prod-06: 早期插件只做定点)
- 流派: 通用; 城市块流派把"重建"做成"再加几块", 不必推倒
- 出处: N9 (论坛 p=670111, 2025-04-26, 3; 视频 Ic0n Gaming 2024-11-04 和 Nilaus 第 27 集 2026-08-27, 4); N4 (Steam 2024-10-28, 3); S20 (论坛 p=684057, 2025-10 ~ 2026-06, 3); lessons-v1 #8
- 状态: 待核实
- 沙盘怎么比: A = 小基地 45 瓶/分钟直接冲火箭, B = 先建 120 瓶/分钟主线再冲; 比到第一枚火箭的时间、总材料, 以及第一次重建 (换铸造厂) 要拆多少

### P-prog-03 【分歧】离开新地星的门槛: 30 到 120 瓶/分钟都有人, 真正的硬条件是军事和自保

### P-prog-04 白瓶不用亲自上天: 第一个平台停在轨道不装推进器
- 情况: 火箭发射井建好, 要白瓶但平台技术还不熟
- 做法: 发一个只有星岩抓取臂 + 破碎机 + 电炉 + 组装机的小平台停在新地星轨道, 不装推进器, 抓星岩做白瓶再投下来; "第一个平台根本不用动"; 同时先建最小弹药闭环 (金属星块 → 破碎机 → 铁矿 → 电炉 → 标准弹匣) 保住平台
- 为什么: 白瓶配方 (2 铁板 + 1 碳 + 1 冰 → 5) 只能在重力 0 处做, 原料全来自星岩; 新地星轨道只有星块、没有星岩撞击 (S13), 最安全; 平台常见死法是断弹断燃料, 不动就没这两条 (S16)
- 代价 / 不适用: 这个平台以后要改成能飞的就得加推进器和炮塔, 2.1.21 后基座越多阻力越大 (SA1), 所以要么重造要么一开始就按"紧凑"设计
- 关联: 白瓶 → 物流系统 → 蓝箱补弹 (defense.md P-def-08); 平台设计归 layout-styles.md P-style-17
- 流派: 通用

### P-prog-05 【分歧】星球顺序: 祝融先 / 雷神先 / 句芒先, 三种都有理由; 玄冥一定最后
- 情况: 第一次离开新地星, 选第一站
- 做法: ① 祝融星先 (最多人): 拿铸造厂、大型采矿机、重炮, 没有污染、金属近乎免费, 回头重建新地星最省 (S1, V25); ② 雷神星先: 拿电磁工厂, 没有敌人、"最简单的外星"(F5), 连空手去都能活 (F4); ③ 句芒星先: 公认最难 (腐坏 + 敌人), 有人主张先啃硬骨头 (S1); 中文 UP 有人走 雷神 → 祝融 → 句芒 → 玄冥。硬约束: "发现星球: 玄冥星"要橙、粉、草三种瓶, 三颗内圈都得先去 (S2); 新地星重炮清巢要去过祝融星 (V6); 沃土要新地星的异虫卵 (facts gleba.overgrowth-soil.needs-biter-eggs)
- 为什么: 三颗内圈星球各出一种瓶和一种工厂, 互不前置, 所以顺序是偏好; 偏好的分野在"先拿产能还是先练难的"
- 代价 / 不适用: 先去句芒的代价是防御材料 (碳纤维要玉玛果链, 火箭炮塔要碳纤维) 全靠本地, 2.1 扩张修好后更吃力 (D19); 先去雷神的代价是电磁工厂运回去要火箭, 而雷神星没有铁铜铀 (F2)

### P-prog-07 每颗星的落地顺序由触发式科技链决定: 第一件事是做"触发那个科技"的动作

### P-prog-09 什么时候上火车: 矿区超过约 500 格、或者一条带不够; 列车长度是最重要的早期决定
- 情况: 新地星中期 (紫瓶前后), 或任何有岛/河的星球

# 知识和技能分类 (给 MCP 调用)

> 2026-10-31。内容很多, 所以按"从哪来、谁来用"分五大类; 每条都有编号、出处、游戏版本、核实状态, 由 knowledge 和 memory 两个 MCP 按类别提供, 各领域 MCP 只取自己需要的那一类。

## 一、游戏本体 (从游戏数据自动生成, 全覆盖, 每个版本重新生成)
不靠检索, 由脚本从本机游戏导出: 原型数据 (`--dump-data`)、API 文件 (`doc-html`)、本地化文件 (官方中文名)、更新日志。
| 类 | 内容 |
|---|---|
| 物品 | 全部物品: 堆叠、重量、火箭载重、燃值、腐坏时间和结果、能种什么 |
| 配方 | 原料、产物、时间、机器类别、能否产能、星球限制、产物概率 |
| 建筑 | 尺寸、速度、能耗、插件槽、流体口和热口位置、机械臂取放点、射程、血量、抗性 |
| 科技 | 前置、所需科技包、解锁内容、触发条件 |
| 星球和地块 | 气压、重力、资源、地块能不能建、能种什么 |
| 敌人 | 血量、速度、射程、伤害、抗性、吸收孢子或污染的量 |
| 品质 | 各等级效果 |
| 中文名 | 官方译名对照 |

## 二、机制 (游戏怎么运转; 来源: 官方文档和 wiki + 沙盘实验)
物流网 (取货顺序、存储、充电)、火车 (信号、寻路、车站、中断、上限)、流体 (管道长度、流量)、电 (供热塔、蒸汽、太阳能、蓄电器)、电路网络 (2.1 红绿线分开)、机械臂和传送带吞吐、腐坏、生物室和农业、敌人 (污染和孢子、扩张、进化、攻击方式)、建设机器人、太空平台 (推力、阻力、星岩)、品质和回收。
每条机制写成"事实 + 沙盘测试", 游戏更新后重跑。

## 三、玩法经验 (老玩家的打法; 来源: 全网攻略 + 沙盘验证)
开局顺序、各星球攻略 (新地星、祝融星、雷神星、句芒星、玄冥星、太空)、科研路线、布局套路 (主线、城市块、火车网、生物室链)、比例和定额、防御打法、常见坑、扩张、太空平台设计、刷品质、大基地。
每条先作为"待核实说法"入库, 沙盘验证后才算事实; 布局套路验证后进模式库。**用于设计按风险分级**: 出处可靠 (官方 wiki / 更新日志 / 多个老玩家说法一致) 且低风险、可回滚的, 可以标"暂用"先用, 同时排沙盘核实, 结果对不上就改并记教训; 高风险的 (联机服务器上的操作、拆东西、不可逆的大规模建设、安全规则) 必须先核实。状态多一档: 待核实 / **暂用** (在用、待核实) / 已核实。

这一类分两层 (有一些东西就是有与众不同的玩法和搭建方法"):
- **事实层** `knowledge/facts.md`: 单条可测的数值和行为, 沙盘实验核实, 回归测试守着。
- **思路层** `knowledge/patterns/`: 什么情况下老手怎么选、为什么、代价、和什么牵连、属于哪个流派; 每条带出处; 核实靠沙盘把两种做法并排比 (设计搜索), 不是单个实验。来源按价值: 老玩家本人 (朋友的基地和回答) > 开发周报的设计意图 > 老玩家长文和分歧帖 > 从说法表里提炼。设计师按"情况"查思路层挑候选, 审查员按它挑毛病; 没比过的只能当候选。

## 四、技能 (能执行的动作, 落在行动类 MCP)
走路寻路、物品和手搓、建造 (蓝图、幽灵、拆除、填海)、设置 (请求、配方、筛选、电路条件)、战斗 (武器、站位、风筝、清巢、炮塔推进)、驾驶 (车、坦克、蜘蛛机甲、火车)、装备 (装甲格子)、研究管理、物流管理、太空平台操作、队友沟通。
每个技能有手册、回归测试和"做完读回核对"。

## 五、本世界知识 (由 memory MCP 管)
地图 (资源、地形、虫巢)、已建设施和它们的产量、队友情报、本服规矩、历史事件和教训。

## MCP 怎么用
- knowledge 提供查询: 按名字查物品/配方/建筑/科技 (中文名和内部名都行)、按主题查机制、按目标查玩法和布局模式; 返回时带出处、版本和核实状态, 设计时默认只用"已核实"的。
- 各领域 MCP 连接时只注入自己领域那一类的摘要, 例如 combat 只带敌人数值和战斗规则, calc 只带配方和机器速度。
- 第一类全部自动生成, 第二、三类靠研究员持续检索和沙盘实验补充, 第五类随游戏实时更新。

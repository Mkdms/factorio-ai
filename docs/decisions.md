# 定下的规矩和理由

| 日期 | 规矩 | 理由 |
|---|---|---|
| 2026-11-07 | 两条路: 沙盘 = 本机无界面服务器 + 我们的模组 + RCON (快, 不算成就, 只在本机); 玩用户账号和联机 = 游戏里什么都不装, 读内存 + 键鼠操作 (慢, 算成就) | 这张图跑过一条 Lua 控制台命令, Steam 成就就关掉; 装模组的图另记一套成就不上传。实测: 不装模组不碰 RCON 的本机新图真拿到了成就 |
| 2026-11-07 | 联机默认只开 1 个 AI 角色 (加上用户自己的账号); 客户端最小化、最低画质、关声音 | 联机不能装模组, 每个 AI 角色要一个游戏客户端, 一台电脑开几个吃不消; 最小化不画画面, 实测不影响动作速度 |
| ~~2026-11-07~~ | ~~沙盘里所有 AI 角色都是服务器里的角色, 只开一个观看窗口~~ (当晚作废: 模型不用模组, 沙盘里也是客户端 + 读内存 + 注入) | ~~不用多开客户端~~ |
| ~~2026-11-07~~ | ~~模组只做模型真用的动作~~ (当晚作废: 模组不给模型用, 只在测试里读真值) | — |
| ~~2026-11-07~~ | ~~每个席位自己选"手脚": 服务器角色 (模组驱动) 或 模拟玩家~~ (当晚作废: 只有模拟玩家一种) | — |
| 2026-11-07 晚 | **模型的手脚只走"不装模组"的路**: 游戏客户端 + 进程外读内存 + 注入客户端发玩家操作, 沙盘和联机同一条路; 沙盘模组只在测试里读真值, 不给模型 | 用户要求: 联机用不了模组, 做两套白做 |
| 2026-11-07 晚 | 别人的项目照搬进来 (复制、自己起名、补测试、NOTICE 署名), 不重写: factorio-mcp 只搬 Windows 和通用部分 (Linux 部分 6 万行不要, 游戏和客户端都是 Windows 版, 要用再从历史打包取), 派对的命令行和 harness 模组 Lua (MIT) 整个搬, 模组 Lua 在游戏外跑 | 用户要求: 照搬比重写快; factorio-mcp 没有许可证文件, 作者允许的是复制加署名 |
| 2026-11-07 晚 | factorio-mcp 的 Windows + 通用部分照原来的署名条件搬进 game/client (NOTICE), 不另问作者 | 用户定: 新项目是同一个项目的重做, 署名就行 |
| 2026-11-07 晚 | 读内存和游戏外跑模组 Lua 先留 Python (lupa 自带真正的 Lua 5.2) | 核过真值的代码都是 Python 写的; npm 上的 Lua 运行时只有 5.3 / 5.4, 模组按游戏的 5.2 写, 数字格式会对不上; 要不要换以后单独算一块 |
| 2026-11-07 晚 | 第一块的顺序: 读内存 (game/memory) → 游戏外跑模组 Lua → 注入层 (game/client) → 命令和动作 (commands/) → 沙盘服务器不装模组、不叫模型跑通一班; 每步有测试才下一步, 旧项目对应文件搬完就删 | 每块搬完能跑才搬下一块 |
| 2026-11-07 | 模组的通道以 UDP 为主 (游戏自带 --enable-lua-udp), 控制台命令只做沙盘实验的备用 | 打"用过控制台"标记的是控制台命令, 不是模组本身; UDP 通道不经过控制台。"装模组的图 Steam 给不给成就"没测完 (2026-11-07 试了一次: 装模组、不发控制台命令, 游戏成就页写"已启用非官方模组, 成就系统将独立于原版游戏另行记录", 另一套计数 0/88; 用户没放东西就停了, 同不同步 Steam 不知道; 测试件 test/manual/mod-achievement.mjs 留着); 没结论前按"模组 = 不算成就"设计 |
| 2026-11-07 | 不改存档、不改内存去抹"用过控制台"的标记 | 那是作弊 |
| 2026-11-07 | 模型手里永远没有 RCON 和 Lua: 只能用我们的命令, 每条都是玩家能做的事 (够得着、用背包里的东西、花真实时间); 生成角色、改时间、存档等管理操作走程序专用的通道, 模型的命令行连不上; 命令白名单由钩子强制 | 用户要求: 模型不能用 RCON 刷物资、改服务器 |
| 2026-11-07 | 和游戏相关的别人的项目全部换成自己写的代码、自己起名; 通用库照常装; 蓝图编辑器照旧用现成的 | 用户要求: 看得懂、全是自己的东西 |
| 2026-11-07 | 文档、注释、提交说明不写人名、不写用户原话; 别的项目只写项目名 | 用户要求 |
| 2026-11-07 晚 | 第二块 = 训练集和大脑驱动一起搬 (不分两块): 模型接进来 (core/brains) 和递给它的积累 (training/) 一起做, 以沙盘里真模型用着训练集跑一班为验收 | 用户要求; 训练集没有大脑用就验不了"递到没递到" |
